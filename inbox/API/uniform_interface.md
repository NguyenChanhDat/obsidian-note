# uniform_interface

## Key Concepts

- the same rules apply everywhere
- the same style is used consistently
- clients don’t need special cases per endpoint
## Important Details

if your api decides:
- updates are done via `POST`
- deletes are done via `POST`
- reads are done via `GET`
then **that is still RESTful** — _as long as it’s consistent_.
